# Project Konversi Suhu

Aplikasi interaktif untuk melakukan konversi suhu.

## Capablility

- Melakukan konversi suhu dari Celcius ke:
    - Fahrenheit
    - Kelvin
    - Reamur

## Requirements

- NodeJS LTS
- IDE VSCode

## How to Run

1. Install dependencies
```sh
npm install
```
2. Run the project using `npm run dev`
```sh
npm run dev
```
